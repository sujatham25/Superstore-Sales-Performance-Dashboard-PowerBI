# Superstore Sales Performance Dashboard

## 📊 Project Overview

The Superstore Sales Performance Dashboard is an interactive Power BI dashboard developed using the Superstore dataset to analyze sales, profit, orders, products, and regional performance.The dashboard helps analyze sales trends, category and sub-category performance, customer segments, and regional sales through interactive visuals and filters.

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Power Query
- DAX

## 📂 Dataset

The Superstore dataset contains information about:

- Orders
- Customers
- Products
- Sales
- Profit
- Quantity
- Categories
- Sub-Categories
- Regions
- States
- Order Dates

## 🧹 Data Preparation

The data preparation process included:

- Checking and correcting data types
- Checking for duplicate records
- Checking for null and blank values
- Cleaning and transforming data
- Preparing the dataset for analysis and visualization

## 📈 Dashboard Features

### KPI Cards

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Sales
- Profit Margin
  
### Visualizations

- Sales Trend
- Sales by Category
- Profit by Sub-Category
- Sales by Segment
- Sales by State
- Sales by Region

### Interactive Filters

The dashboard includes filters for:

- Order Date
- Region
- Category
- Segment

## 🔍 Key Analysis

The dashboard provides analysis of:

- Overall sales and profitability
- Sales trends over time
- Category and sub-category performance
- Customer segment performance
- Regional sales performance
- State-wise sales
- Profit margin

## 🎯 Project Objective

The objective of this project is to transform raw sales data into meaningful business insights through an interactive Power BI dashboard and support data-driven decision-making.
